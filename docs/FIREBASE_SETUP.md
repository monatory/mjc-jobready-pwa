# Firebase 연동 설정 가이드 (10분)

> 2026-08-30 결정: 기존 Firebase **계정**(MJC-CAT 관리 계정)을 그대로 쓰되, **프로젝트는 분리**한다.
> MJC-CAT의 Rules(익명 설계)와 MJC-READY(실명 필수)가 상충하고, 공용 프로젝트에 Rules를
> 배포하면 실서비스 중인 MJC-CAT을 건드릴 위험이 있기 때문. 새 프로젝트는 기존 계정에서
> 2분이면 만들 수 있어 "별도 가입 대기"가 필요 없다.
>
> 아래 설정을 마치기 전까지 앱은 **로컬 모드**(브라우저 저장)로 지금처럼 동작한다 — 깨지는 것 없음.

## 1. 새 프로젝트 생성 (2분)

1. https://console.firebase.google.com — 기존 계정(mjc-career-pwa 관리 계정)으로 로그인
2. **프로젝트 추가** → 이름 `mjc-ready-pwa` → Google 애널리틱스 **사용 안 함** → 만들기
3. 프로젝트 홈에서 **웹 앱 추가**(</> 아이콘) → 닉네임 `mjc-ready-web` → 등록
   (호스팅 설정은 체크하지 않음 — GitHub Pages 유지)

## 2. firebaseConfig 붙여넣기 (1분)

웹 앱 등록 직후 나오는 `firebaseConfig` 값 6개를 복사해서
**`src/lib/firebase.ts`의 `firebaseConfig`** 자리(▼▼▼ 표시)에 붙여넣는다.
붙여넣고 커밋·push하면 그 순간부터 클라우드 모드.

> 나중에 다시 보려면: 프로젝트 설정(톱니) → 일반 → 내 앱 → SDK 설정 및 구성

## 3. Authentication 켜기 + 마스터 계정 생성 (3분)

1. 빌드 → **Authentication** → 시작하기
2. 로그인 방법 탭에서 **이메일/비밀번호** 사용 설정 → 저장
3. 같은 탭에서 **익명** 사용 설정 → 저장 (학생 응답 제출용)
4. **사용자 탭 → 사용자 추가**: 이메일 `monatory82@gmail.com` + 사용할 비밀번호 입력
   ⚠ **이 단계를 프로바이더 켠 직후 바로** 할 것 — 마스터 이메일을 다른 사람이 먼저
   등록하는 것을 막는다. 앱은 이 이메일을 마스터로 인식한다(Rules에도 고정).

## 4. Firestore 만들기 + Rules 게시 (3분)

1. 빌드 → **Firestore Database** → 데이터베이스 만들기 → 위치 `asia-northeast3 (서울)`
   → **프로덕션 모드**로 시작
2. **규칙 탭** → 저장소의 **`firestore.rules`** 파일 내용 전체를 붙여넣기 → **게시**
   ⚠ 반드시 새 프로젝트(mjc-ready-pwa)에서만 게시 — mjc-career-pwa에 게시 금지

## 5. 승인된 도메인 (1분)

Authentication → 설정 → **승인된 도메인**에 `monatory.github.io` 추가
(localhost는 기본 포함 — 로컬 개발은 그대로 됨)

## 완료 후 자동으로 되는 것

| 기능 | 설정 전 (로컬 모드) | 설정 후 (클라우드 모드) |
|---|---|---|
| 학생 응답 | 브라우저에만 저장 | 결과지 도달 시 Firestore 제출 → 관리자·상담사 화면에 실측 표시 |
| 상담 기록·연계·취업 | 브라우저별 저장 | **상담사 간 공유** (워크스페이스 열 때 동기화 + 저장 즉시 반영) |
| 연계기관 등록부 | 브라우저별 | 상담사 공유 |
| 교직원 계정 | 로컬 계정 | 이메일 가입 → Firebase Auth (승인 흐름 동일) |
| 마스터 로그인 | 코드 고정 해시 | 콘솔에서 만든 본인 이메일 계정 (해시가 저장소에서 필요 없어짐*) |

\* 클라우드 전환이 안정화되면 로컬 마스터 해시 제거 예정 (요청 시 바로 제거).

## 확인 방법

1. 배포 후 `#/admin` → `monatory82@gmail.com`으로 로그인 → 정상 진입이면 Auth OK
2. 학생 흐름 완주 → 결과지 하단 "응답이 안전하게 제출되었습니다" 표시 + 관리자 배너가
   "실측 데이터 — 응답 1건"으로 바뀌면 Firestore OK
3. 다른 브라우저(또는 다른 PC)에서 상담사 로그인 → 연락 기록이 보이면 공유 OK
