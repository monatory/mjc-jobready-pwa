## 2. 핵심 변경 (파일럿 전 안정성)

- **학생 제출**: `setDoc(…, { mergeFields })`로 이번 세션 필드만 교체 — 재응시가 상담 신청·교정 이력을 지우지 않음. 같은 탭 제출 직렬화.
- **상담 기록**: `pullShared`가 로컬 캐시를 원격 스냅샷으로 통째 교체, 저장 base 없으면 빈 기록 — 삭제된 학생 기록 부활·잔존 차단. 회차 원소 형태 검사.
- **삭제·수정 기준**: `StudentRecord.doc_id`(실제 문서키). 규칙 `ready_responses` delete = `isCounselSide()`.
- **규칙 게시**: 삭제 권한 축소 + `validResponse`에 학과·학년·휴대전화(`010-0000-0000` 형식 또는 빈 값) 강제. `firebase deploy --only firestore:rules` 성공.
- **상담사 큐**: 상담을 직접 신청한 학생은 진학·창업 Route라도 연락 우선 큐 포함.
- **결과지**: 미정(UNDECIDED) "진로탐색 Route", Route 부제 대비 5.0, 기본정보만 입력해도 재개 모달, 320px 척도 라벨 넘침 0, 상담 신청 안내 상태별 분기, 늦게 도착한 추천 Master 반영.
- **계정**: 삭제(tombstone) 계정 "삭제된 계정" 구역 + 복구 버튼, 클라우드 조회 실패 시 직접 등록 잠금, 저장소 차단 분기 signOut.
- **추천활동**: 길이 검증을 UTF-8 바이트로(규칙과 단위 일치), 코드 형식 아닌 문서 제외.
- **CSV**: 통합 시트 "(종료)" 표기, 04시트 문항별 gate/critical, 버전 컬럼은 응답 저장값.
